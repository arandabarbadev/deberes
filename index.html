      Sincronizar

      Guarda tus datos cifrados dentro de tu repo de GitHub, así los tienes igual en el móvil y en el ordenador.

      ¿Cómo consigo el token?
      1. En GitHub: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens
      2. Generate new token → en Repository access elige Only select repositories → deberes
      3. En Permissions → Repository permissions → Contents: Read and write
      4. Genera y copia el código (empieza por github_pat_)

      El token solo puede tocar este repo, y tus datos van cifrados con tu contraseña: nadie más puede leerlos. No compartas ninguno de los dos.

      Tus datos se guardan en este navegador y, con la sincronización activada, cifrados en GitHub.
