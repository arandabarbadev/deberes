# Mis deberes 📚🏁

Web para recordar la tarea de cada día. Dos apartados: **pendientes** y **completados**.

Al añadir una tarea se ponen tres cosas: **asignatura**, **fecha de entrega** y **en qué consiste**.

- Cuando no queda ninguna tarea pendiente, aparece el mensaje motivador:
  > *El esfuerzo de hoy es el éxito del mañana.*
- Cuando pasa el día de entrega, la tarea se elimina sola.
- Los datos se guardan en el navegador y, con la sincronización de ⚙️,
  también cifrados en GitHub (`datos.json`): así están igual en el móvil y en el ordenador.

Hecha con HTML, CSS y JavaScript puro, sin frameworks.
